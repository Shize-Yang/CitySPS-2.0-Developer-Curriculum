## What belongs here

课程需要满足至少一个条件：

- 对 **Foundation Model / World Model / Agent** 的核心方法有系统讲解；
- 包含高质量 assignment / code，可直接帮助实现 CitySPS 模块；
- 对 distributed training、model-based RL、complex systems 等底层能力有明显补充。

不把一般性的入门课或与 CitySPS 关系较弱的资源堆进来。

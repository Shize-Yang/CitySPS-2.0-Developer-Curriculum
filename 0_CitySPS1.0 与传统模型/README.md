## What to extract from this section

阅读这一部分时，重点不是复述旧模型，而是提取对 CitySPS 2.0 仍然有效的设计：

- **State**：城市状态如何表示？人口、活动、土地利用、交通、设施如何连接？
- **Agent / Actor**：个体、家庭、企业、政府等主体如何表示？
- **Dynamics**：城市状态如何随时间更新？
- **Interaction**：交通—土地利用—人口—经济之间如何反馈？
- **Intervention**：政策与规划行动如何进入模型？
- **Calibration & Validation**：模型如何与真实城市数据校准和验证？

> CitySPS 2.0 的目标不是抛弃传统城市模型，而是在保留其机制建模与政策模拟能力的基础上，引入 Foundation Model、Agent System 和 World Model 等新范式。
